# IEX releases

Binary releases of **IEX (Infinity Extender)**, an EEex-compatible engine extender for Baldur's Gate EE,
Baldur's Gate II EE and EET (engine 2.7.3), on Windows x64 and Linux x64.

This repository only hosts the release archives. Install IEX with [Candlekeep](https://github.com/sad0), or by hand:

1. Download `IEX-<version>-windows-x64.zip` (or `-linux-x64.zip`) from [Releases](../../releases).
2. Extract `IEX/` and `SpellSlots/` into the game folder, next to the game executable.
3. Install with WeiDU: `setup-IEX.exe` (copy of `weidu.exe`), component #0.
4. Start the game with `IEXLauncher.exe` (Windows) or `IEX/bin/linux64/iex-launch.sh` (Linux).

IEX is a preview: please report problems on the Sado Mods Discord.
